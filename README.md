# InnoJudge

**以视频证据支持物理实验操作评测。**

## 产品描述

**对于**组织初中物理实验评测的教师与评分员，

**他们**需要统一评分标准、提高复核效率，并保持人工评分独立，

**InnoJudge 是一个**AI 辅助实验视频评测平台，

**它能够**管理量表与任务、支持独立评分，并按评分点定位视频证据，

**不同于**仅输出总分或评语的视频分析工具，

**我们的产品**将人机评分分开记录，让教师有据复核、评分员不受 AI 结论干扰。

> 当前状态：需求整理与方案设计阶段。代码和测试目录为预留骨架，尚无可运行系统、已发布版本或可复现的启动命令。下述功能均为规划目标。

## 核心工作流

1. **创建任务**：教师填写任务基本信息，上传或选择评分量表，并编辑确认评分标准。
2. **准备素材**：选择待评测的实验视频；首期以离线视频和手动上传为基础。
3. **分配评分**：将具体评分任务分配给评分员，按量表完成独立人工评分。
4. **辅助分析**：生成视频阶段、错误操作时间标注、分项评分及反馈，并关联可核查的证据。
5. **查看结果**：教师在权限范围内查看人机评分结果，点击评分点定位到对应视频片段。

评分员入口不展示 AI 评分或分析结果，避免干扰独立判断；后台管理与教师入口的具体权限矩阵仍需细化。AI 输出是辅助信息，不预设其直接作为最终成绩。

## 需求边界

- 首期场景为初中物理实验，例如凸透镜成像实验；具体实验清单与量表需确认。
- 量表包含分组、评分点、分值、满分标准、扣分项及危险操作说明。
- 实时视频预览、硬件状态与身份识别属于后续评估事项，不作为现成能力。
- 多评分员的评分范围、成绩汇总规则、看板指标及任务扩展字段尚待确认。
- 技术栈、接口协议、性能目标、部署方式与交付日期尚未定版。

需求依据为 `pdfdocs/` 内的物理实验评测 PRD。材料中的示例、评论和待讨论事项不等同于已确认产品决策；结构化需求与待确认问题见下列文档。

## 参与与数据保护

先阅读需求及其待确认事项，再按[贡献指南](CONTRIBUTING.md)提交讨论或文档变更。运行环境和代码实现确定后，将补充可验证的安装、测试及部署说明。

不要在公开仓库、Issue 或 PR 中上传真实学生视频、身份信息、账号凭据或可直接访问素材的链接。使用经授权、脱敏或合成的测试材料。仓库尚未选定开源协议，不应据此推断已取得代码或实验视频的使用授权。
