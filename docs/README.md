## 需求来源与解释规则

原始参考材料存放在 `../pdfdocs/`，为物理实验评测 PRD。原始 PDF 保持不变，便于核对。

1. 区分产品需求、示例数据、评论与待讨论事项。源材料中字段、分值和场景不一致的示例不作为正式接口或评分规则。
2. 平台文档统一使用 InnoJudge；以初中物理实验为业务场景，不将其他实验操作示例直接作为首期实验清单。
3. 需求变更先明确决策，再同步问题定义、产品需求与首页。
4. 技术栈、API、模型服务、性能指标和交付日期在未确认前不得写成定案。
5. 实现、测试、部署与版本发布仅在具备可核查证据后标为完成。
6. 文档及示例不得携带真实学生身份、视频访问凭据或内部服务地址。
