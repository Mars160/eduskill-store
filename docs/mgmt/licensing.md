# 许可状态与授权边界

## 1. 仓库许可尚未选定

当前没有 `LICENSE` 文件，不应宣称本仓库采用 MIT、Apache-2.0、GPL 或其他开源协议。公开可见不等于授予开源使用、修改或再分发许可。

维护者需在发布前确认代码、文档及第三方材料的权利归属，选定协议后加入准确的协议正文与版权信息，再同步 README 和贡献指南。本文仅说明待决状态，不替代法律协议。

## 2. 仓库许可与平台 Skill 授权不同

即使未来平台代码开源，也不意味着用户上传的 Skill 自动适用相同协议。创作者需要独立决定并明确内容授权；价格与授权范围是两件不同的事。

- 免费 Skill 不自动意味着允许 Fork、再分发或商业再销售。
- 收费 Skill 不自动意味着购买者获得版权或无限制衍生权。
- 能阅读或执行，不自动意味着能下载、修改或对外发布。
- 技术上的 Fork 功能必须遵守实际授权，不应绕过收费与访问控制。

## 3. 付费衍生机制

当前业务方向：A 的 Skill 定价为 a，B 在其基础上新增部分定价为 b，衍生 Skill 标价为 a + b，收益归属分别对应 A 和 B。

上线前仍需确认：

- A 如何允许或禁止衍生，是否需要逐次授权。
- 多层衍生及多个上游组合的授权与分配规则。
- 上游变价、升级、删除和下架对既有购买者及衍生作品的影响。
- 平台抽成扣除方式、退款、结算与税费处理。
- 署名、来源追踪、付费内容可见性与侵权争议流程。

这些规则不能仅靠价格公式解决，也不得由技术实现自行决定。
